UNIVERSITY STUDENT PORTAL - BEGINNER PROJECT

FILES
- index.html: page content and structure
- style.css: design and responsive layout
- script.js: mobile menu and demo forms
- assets/: logo and favicon SVG files

HOW TO RUN
1. Extract UniversityWebsite.zip.
2. Open the UniversityWebsite folder in Visual Studio Code.
3. Open index.html in a browser, or install the Live Server extension.
4. Right-click index.html and choose "Open with Live Server".

CUSTOMIZATION
- Replace the sample university name and department details in index.html.
- Replace assets/university-logo.svg with your own logo if desired.
- Change colors in the :root section of style.css.

NOTE
The registration and contact forms are front-end demonstrations only.
They do not save data to a database or send email. A backend is required
for real student accounts, secure login, database storage and email delivery.

The included logo is a generic editable SVG placeholder, not an official
Islamic University emblem. Use an authorized official logo where required.
